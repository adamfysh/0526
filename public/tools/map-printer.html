Internal — Not Linked
Route
2 waypoints = a normal origin→destination route. 3+ = a multi-leg chain (like a real reroute around several chokepoints in sequence) — each leg is computed and stitched into one path.
Vessel class
Auto-checks the closures below where a class physically can't fit through (draft/beam/LOA limits at Suez, Panama, Malacca) — not a preference, and not the geopolitical closures (Hormuz, Bab-el-Mandeb, etc.), which any class can transit. You can still check/uncheck anything manually afterward.
Simulate closures
Checking a closure computes both the original route and the re-route, and draws the original ghosted behind the re-route so the detour is visible at a glance. Northwest Passage and Bering are always excluded as non-commercial. Danish Straits / Dover aren't offered yet — the routing graph doesn't tag them as distinct passages.
Canal transit cost
Always applied — not a per-route toggle. Panama and Suez tolls plus average dwell/wait are converted to an nm-equivalent cost and added to any route that uses them, so the engine only routes through a toll canal when it's still cheaper net of that cost, the same way it already weighs risk-premium zones. Set either to 0 to treat that canal as toll-free.
Illustrative defaults (~$450k Panama toll + ~1 day dwell, ~$350k Suez toll, converted at ~$450/nm all-in vessel cost) — edit with a real figure for your vessel/voyage if you have one. Vessels that physically can't fit a canal at any price (VLCC/Capesize/ULCC — see Vessel class above) are hard-excluded instead, since a toll number is meaningless there.
Trade flow ensemble
The top bilateral trade corridors by annual value (2024, from the CDM's own trade-flow data), each drawn as a great-circle line weighted by $/yr — the broader context around whatever single route you're arguing about. Endpoints are each country's largest port by throughput, not the actual load/discharge port for any one voyage, and lines are geometric great circles, not routed around chokepoints — illustrative corridor weight and rough geography, not a precise track. A flow is drawn in red when it's tagged as transiting a chokepoint you've currently checked closed above, so you can see which trade is actually exposed.
Custom zones paste coords import
Draw a zone with the polygon tool in the map's top-right corner, or click "paste coords" to type/paste a list of GPS points instead (cyclone season, ice extent, anything with no clean API or a shape you already have coordinates for). Saved zones persist in this browser and reload every time you open this page.
Routes on map clear all
Routes are computed live against a real global maritime routing graph (9,708 nodes / ~16,000 edges) — the same network searoute-py uses internally. Distances/durations are estimates for exploration, not voyage planning. Custom "avoid"/"premium" zones (including loaded JWC listed areas) actually influence computed routes while visible — hide a zone to exclude it from routing. The map above is Mercator (standard for an interactive editor); PNG export is redrawn independently in an Equal Earth projection, not a screenshot of the map above.
