Checking a closure computes both the original route and the re-route, and draws the original ghosted behind the re-route so the detour is visible at a glance. Northwest Passage and Bering are always excluded as non-commercial. Danish Straits / Dover aren't offered yet — the routing graph doesn't tag them as distinct passages.
Custom zones import
Use the polygon tool in the map's top-right corner to draw a zone (cyclone season, ice extent, anything with no clean API). Saved zones persist in this browser and reload every time you open this page.
Set an origin, destination, and any closures, then compute a route.
Routes are computed live against a real global maritime routing graph (9,708 nodes / ~16,000 edges) — the same network searoute-py uses internally. Distances/durations are estimates for exploration, not voyage planning. PNG export rasterizes the map div in your browser (html2canvas) — if the basemap tiles come out blank, that's a cross-origin canvas restriction on the tile provider, not a bug in the routes/zones themselves.
